# Brag Plan: Vilas Studio — Wildstem Florals demo (Premium hero)

## What is this app?
Vilas Studio builds websites for local businesses. Every demo has a price toggle: Basic ($300 + $50/mo, still hero) vs Premium ($500 + $80/mo, scroll-scrubbed hero video).

## The angle
Flip the toggle on camera. Same florist site, two prices — the hero literally comes alive at $500.

## Hook (0–3s)
"One florist website. Two prices." with the real Vilas bar (toggle on $300 + $50/mo) over the still hero.

## Key moments
- Basic: still hero, "A still hero, done well." (site copy)
- Toggle flips (beat-locked ~7.35s) → hero video starts
- Premium: exploded bouquet assembles, flies to the shop door, camera enters. "Picked, not produced." headline + "Order for pickup" CTA (from the site)

## Outro / punchline
Vilas Studio — "A website that looks expensive. It wasn't." + price recap + vilas.studio.

## User flow worth showing
Demo page → toggle tier → scroll hero plays (scrubbed, shown sped up).

## Tone
- Preset: default; direction: warm, tasteful, quietly confident
- Interpretation: calm bone/cream field, serif headline from the demo, one big motion moment

## Format: vertical — 1080x1920
## Duration: ~22.6s

## Visual identity
- Background #efe9dd, surface #f6f1e8, ink #1f1a14, muted #4d4638, line #d9d0c1, accent #8a5a2b
- Demo accent (florist): #B14A63
- Display: Fraunces (florist), Syne (Vilas); wordmark Space Grotesk 500; labels Space Mono
